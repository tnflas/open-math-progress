# Contributing

Open Math Progress welcomes source links, research updates, correction reports, and public notices.

Mathematical correctness and scientific priority are not independently reviewed by OMP.

## 1. Submit a New Research Source

Use GitHub Issues to suggest an additional upstream repository or research index.

Provide:

- Repository or resource URL.
- Description of its mathematical content.
- Available data format, if known.
- Relevant license or attribution information, if known.

Source suggestions do not guarantee integration.

## 2. Submit a Solution or Progress Report

Open GitHub Discussions and choose **Solution & Progress Reports**.

Provide:

- The mathematical problem or precise variant.
- The original report or research link.
- What the original source claims.
- Known AI involvement, if disclosed.
- Available verification evidence, if any.

Do not claim that OMP has verified the result.

## 3. Submit a Research Notice

Choose **Research Notices** in Discussions.

Notices may concern earlier research, parallel work, or academic attribution.

Public notices are not ownership applications and do not confer scientific priority.

Only publish information you are willing and authorized to disclose.

## 4. Submit a Correction or Response

Choose **Corrections & Responses**.

Identify the exact source record and explain the requested correction.

Include public supporting material when available.

A correction request does not imply that the maintainers have adjudicated an academic dispute.

## 5. Improve the Software

Use Pull Requests for code, documentation, or parser improvements.

Please include appropriate tests for changes affecting source ingestion, deduplication, or status classification.

Do not execute untrusted source scripts as part of indexing.

## 6. Licensing and Conduct

Read [Data License](DATA_LICENSE.md), [Research Ethics](RESEARCH_ETHICS.md), and [Code of Conduct](CODE_OF_CONDUCT.md).

Do not submit third-party copyrighted materials without appropriate authorization.

For practical instructions, see [Submission Guide](docs/SUBMISSION_GUIDE.md).
