# Submit Research Without Writing Code

Open Math Progress supports public submissions through GitHub Issues.

## Register a New Mathematical Problem

1. Open the repository's Issues tab.
2. Select **New issue**.
3. Choose **Register a New Mathematical Problem**.
4. Enter its title, statement, original reference and field.
5. Submit the issue.
6. The automated system assigns `OMP-U-<issue number>`.
7. Find the resulting record in [Community Problems](COMMUNITY_PROBLEMS.md).

Registration does not certify novelty, correctness or priority.

## Upload a Research Contribution

1. Find the existing problem ID in the community index or data index.
2. If the problem is absent, register it first.
3. Choose **Submit Research Contribution** from New issue.
4. Enter Problem ID, title, authors, abstract and reported status.
5. Add a public PDF or manuscript link.
6. Submit the issue.
7. The program creates a unique Contribution ID and a public page.

For GitHub-supported files, you can attach the manuscript to
the Issue description or a comment by dragging it into the editor.
Copy the generated attachment URL into the manuscript-link field.
Alternatively, provide a Zenodo, arXiv or other public URL.

GitHub file attachment availability and permitted file types depend
on GitHub's current restrictions. OMP does not copy attachments into
Git history.

## Important Limits

- GitHub authentication is required to submit an Issue.
- OMP does not verify mathematical correctness or scientific priority.
- Contributors must be authorized to share their submissions.
- Notices of prior research or attribution disputes belong in Discussions.
- Public submissions can require moderation for privacy and abuse.
- An existing indexed problem may have multiple independent candidates.
  An OMP ID identifies a record, not a certified unique mathematical problem.
