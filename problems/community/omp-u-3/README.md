# Pula's Odd-Weight Characterization Problem

**Problem ID:** `OMP-U-3`

**Mathematical verification:** Not assessed.

## Statement

Let \(L\) be a Latin square. An integer \(k\)-weight is a function assigning an integer to each cell such that every row sum, column sum, and symbol sum equals \(k\).

  Pula proved that Latin squares with an odd-block pattern of the Cayley table of a cyclic group of even order have no odd-weights.

  **Question:** Is the converse true? More precisely, must every Latin square admitting no odd-weight have an odd-block pattern of a cyclic group of even order?

  Source: Kyle Pula, *A Generalization of Plexes of Latin Squares* (2010), Section 5, Question 1.
